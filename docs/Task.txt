Задача 4: Трансформация сериализуемых
объектов
Цель задачи
Проявить знания таких механизмов языка С++ как шаблонное метапрограммирование, работа с
динамической памятью, вводом / выводом и обработкой ошибок на примере задач сериализации и
десериализации объектов.

Навыки студента
-​ Умение разрабатывать приложения на С++ с применением шаблонов
- Умение выстраивать и объяснять стратегию обработки ошибок в программе на С++

Требования к выполнению задачи
Проект приложения на С++ должен:
-​ Иметь систему сборки
-​ Иметь юнит тесты
-​ Демонстрировать поведение программы согласно описанному техническому заданию
-​ Задание требуется выполнить в объектно-ориентированном стиле с использованием шаблонных
классов и функций

Подготовительные материалы
В данной задаче требуется написать консольное приложение принимающее на вход поток данных в одном
формате представления и преобразующее данные в другой формат предстаставления.
Для этого требуется поддержать:
-​ Чтение данных из входного формата представления: JSON, TOML, XML
-​ Преобразование прочитанного документа в абстрактное дерево
-​ Преобразование абстрактного дерева в заданный выходной формат представления: JSON, TOML,
XML
Входной формат представления задан первым аргументом приложения в командной строке. Выходной
формат представления задан вторым аргументом приложения в командной строке. Входной документ
подается в стандартный поток ввода программы (stdin). Выходной документ должен быть выведен в
стандартный поток вывода программы (stdout). Ошибки требуется выводить в стандартный поток ошибок
(stderr).
В ходе данной задачи предполагается самостоятельное написание обработчиков протоколов
представления JSON, TOML, XML без использования сторонних библиотек.
Трансформация типов данных в форматах JSON, TOML, XML является однозначной - другими словами
поддерживается минимальный пересекающийся набор типов данных.
Обработка синтаксиса представлений должна быть реализована с наглядным представлением ошибок
парсинга в одной из современных парадигм обработки ошибок С++.

Ссылки на материалы и справочные данные
Для целей тестирования предлагается исполнить программу трижды с последовательностью
преобразований входных данных: JSON => TOML; TOML => XML; XML => JSON (или в любом другом
порядке) и сравнить изначальные данные и данные, полученные в конце сценария.
